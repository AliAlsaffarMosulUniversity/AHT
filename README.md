# رحلة الاجتماعيات — الصف الخامس الابتدائي

تطبيق ويب تعليمي مبني على كتاب الاجتماعيات للصف الخامس الابتدائي (وزارة التربية العراقية، الطبعة الثانية عشرة 1447هـ / 2025م)، على نمط تطبيق «مختبر العلوم».

- 3 وحدات و8 فصول: ملخص لكل درس مع خرائط الكتاب وصوره، وبطاقات كلمات، واختبار لكل فصل.
- 374 سؤالاً، و«تحدي البطل» بعشرين سؤالاً من كل الكتاب، ونجوم تُحفظ على الجهاز.
- وضع ليلي ونهاري، ويُثبَّت على الهاتف والحاسوب ويعمل دون إنترنت.

افتح `index.html`، أو فعّل GitHub Pages على الفرع `main`.
